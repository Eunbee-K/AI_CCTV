## 실행 방법

**`실행하기.bat` 파일을 더블클릭하세요.**

서버가 뜨고 브라우저가 자동으로 열립니다. 다른 설치 과정은 없습니다.

- 접속 주소: http://localhost:8080
- 종료: 검은 창에서 `Ctrl+C` 또는 창 닫기

> 파이썬이 설치돼 있지 않으면 안내 문구가 뜹니다.
> [python.org](https://www.python.org/downloads/)에서 3.12 이상을 설치할 때
> **"Add Python to PATH"를 반드시 체크**한 뒤 다시 실행하세요.

## 사용 순서

| 순서 | 화면에서 할 일 |
|---|---|
| 1 | **영상 추가** — 화면 왼쪽 아래에 영상 파일을 끌어놓거나 [파일추가] |
| 2 | **관로 구분 선택** — 오른쪽 위 [신설] / [노후] |
| 3 | **[분석 실행]** — 영상 1개. 여러 개면 [전체 분석] |
| 4 | **결과 검수** — 표에서 행을 눌러 해당 장면 확인, 결함명·등급 수정 |
| 5 | **[보고서 정보]** 입력 후 **[보고서 출력]** — 야장 PDF·엑셀 조사표 |

분석 시간은 관로 1개당 **1~4분**입니다(CPU 기준). 영상 길이에 비례합니다.

## 두 개의 AI가 함께 판단합니다

```
영상 업로드 → 프레임 추출(1초) → AI 분석 → 결과 통합 → 검수 · 출력
                                    │
                    ┌───────────────┴───────────────┐
              판독기 (YOLO11-L)              분류기 (EfficientNet-B0)
              결함 위치를 박스로              화면 전체를 한 장으로 판정
              16종 탐지                      24종 분류
                    └───────────────┬───────────────┘
                            합집합 (Union)
                        1개 이상 검출 시 후보 등재
```

두 모델은 서로 다른 것을 놓칩니다. 판독기는 경계가 뚜렷한 국소 결함(균열·파손·
퇴적)에 강하고, 분류기는 화면 전체 특징으로 판단하는 결함(침하·변형)에 강합니다.
직렬로 두면 앞단이 놓친 것을 뒷단이 볼 수 없으므로 **병렬로 배치**했습니다.

**최종 판단은 사람이 합니다(Human-in-the-Loop).** AI는 결함 후보를 제시하고,
판독자가 검토·승인합니다.

## 성능 (검증 데이터셋 기준)

학습에 쓰지 않은 독립 검증 데이터셋 12종 결함 유형으로 측정했습니다.

| 항목 | 결과 |
|---|---|
| **결함 유무 식별** (정상 / 결함) | **96%** |
| **결함명 식별** (두 AI 합집합) | **90%** |
| — 판독기 단독 | 88% |
| — 분류기 단독 | 91% |

**검증셋 제외 기준** — 데이터가 부족한 희소 결함, 학습 데이터와 중복되어
독립 검증셋을 구성할 수 없는 유형은 제외했습니다.

## 보안

**기본 구성은 외부와 통신하지 않습니다.** 두 모델 파일이 이 PC 안에서 직접
실행되며, 영상과 분석 결과가 외부로 나가지 않습니다.

화면에서 켤 수 있는 **LLM 판독**만 예외입니다. 이 기능은 OpenAI·Google API를
호출하므로 외부로 데이터가 나갑니다. **기본은 꺼져 있고**, 켜기 전에 화면에
주의 문구가 표시됩니다.

## 알려진 한계

정직하게 적어 둡니다.

- **신설관로의 미세한 결함은 잡기 어렵습니다.** 현재 모델은 관종을 나누지 않고
  학습했습니다. 향후 신설·노후를 나눠 파인튜닝할 계획입니다.
- **변형(DF) 유형의 성능이 가장 낮습니다.** 관 아래쪽이 눌린 형태는 화면에서
  윤곽 변화가 작아, 프레임 한 장으로 판단하기 어렵습니다.
- **현장 베타테스트는 아직 진행 전입니다.** 위 성능은 검증 데이터셋 기준이며,
  실제 현장 적용 결과는 2026년 시범 적용에서 확인할 예정입니다.
