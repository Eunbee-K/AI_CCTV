# AI 기반 하수관로 CCTV 영상 자동분석 시스템

하수관로 CCTV 영상에서 결함을 자동으로 찾아 조사표를 만드는 프로그램입니다.

---

## 실행 방법

**압축을 폴더에 푼 뒤 `실행하기.bat` 을 더블클릭하세요.**

> 압축 파일 안에서 바로 실행하면 동작하지 않습니다. 반드시 풀어놓고 실행하세요.

### 처음 실행할 때 (한 번만, 5~15분)

검은 창이 뜨면서 필요한 프로그램을 **자동으로 내려받아 설치합니다.**
인터넷에서 약 1GB를 받으므로 회선에 따라 5~15분 걸립니다.
**설치가 끝나면 브라우저에 분석 화면이 저절로 열립니다.**

중간에 창을 닫지 마세요. 닫았더라도 다시 실행하면 받다 만 지점부터 이어서 받습니다.

### 두 번째부터

**바로 분석 화면이 뜹니다.** (설치 과정을 건너뜁니다)

- 접속 주소: http://localhost:8080
- 종료: 검은 창에서 `Ctrl+C` 또는 창 닫기

### 파이썬이 없는 PC라면

설치할지 물어보는 문구가 뜹니다. **`Y`를 누르면 자동으로 설치**합니다.
자동 설치가 안 되면 [python.org](https://www.python.org/downloads/)에서
3.12 이상을 받아 설치하되, 설치 첫 화면의
**"Add Python to PATH"를 반드시 체크**한 뒤 다시 실행하세요.

> **이 PC의 파이썬 환경을 건드리지 않습니다.** 필요한 패키지는 `app\.venv`
> 폴더 안에만 깔립니다. 지울 때는 폴더째 삭제하면 흔적이 남지 않습니다.

## 사용 순서

| 순서 | 화면에서 할 일 |
|---|---|
| 1 | **영상 추가** — 화면 왼쪽 아래에 영상 파일을 끌어놓거나 [파일추가] |
| 2 | **관로 구분 선택** — 오른쪽 위 [신설] / [노후] |
| 3 | **[분석 실행]** — 영상 1개. 여러 개면 [전체 분석] |
| 4 | **결과 검수** — 표에서 행을 눌러 해당 장면 확인, 결함명·등급 수정 |
| 5 | **[보고서 정보]** 입력 후 **[보고서 출력]** — 야장 PDF·엑셀 조사표 |

> **[신설]을 고르면 화면에 `LLM 판독` 줄이 나타납니다.** 세 번째 의견으로
> 쓰는 선택 기능이며, 자세한 내용은 아래 "세 번째 의견 — LLM 판독"을 보세요.

분석 시간은 관로 1개당 **1~4분**입니다(CPU 기준). 영상 길이에 비례합니다.

## 두 개의 AI가 함께 판단합니다

```
영상 업로드 → 프레임 추출(1초) → AI 분석 → 결과 통합 → 검수 · 출력
                                    │
                    ┌───────────────┴───────────────┐
              판독기 (YOLO11-L)              분류기 (EfficientNet-B0)
              결함 위치를 박스로              화면 전체를 한 장으로 판정
              16종 탐지                      24종 분류
                    └───────────────┬───────────────┘
                            합집합 (Union)
                        1개 이상 검출 시 후보 등재
```

두 모델은 서로 다른 것을 놓칩니다. 판독기는 경계가 뚜렷한 국소 결함(균열·파손·
퇴적)에 강하고, 분류기는 화면 전체 특징으로 판단하는 결함(침하·변형)에 강합니다.
직렬로 두면 앞단이 놓친 것을 뒷단이 볼 수 없으므로 **병렬로 배치**했습니다.

**최종 판단은 사람이 합니다(Human-in-the-Loop).** AI는 결함 후보를 제시하고,
판독자가 검토·승인합니다.

## 세 번째 의견 — LLM 판독 (선택)

두 모델은 **노후관로** 데이터로 학습했습니다. 신설관로는 학습 데이터가 얇아
시공품질 관점의 미세한 결함을 놓칠 수 있습니다. 그 구간을 메우려고
범용 멀티모달 LLM(**Gemini + GPT**)에게 같은 장면을 한 번 더 묻습니다.

```
프레임 → 판독기 · 분류기 (이 PC 안에서 실행)
              +
         LLM 판독 (외부 API · 선택) → 세 의견을 나란히 표에 표시
```

| 항목 | 내용 |
|---|---|
| 언제 보이나 | 오른쪽 위에서 **[신설]** 을 골랐을 때 |
| 기본 상태 | **꺼짐** — 직접 켜야 동작합니다 |
| 쓰는 모델 | Gemini + GPT 두 곳에 동시에 묻습니다 |
| 같이 보내는 것 | 결함 유형별 **예시 사진**(`assets/llm_examples`, 237장) |
| API 키 | 화면에서 입력하며, **디스크에 저장하지 않습니다** |

**예시 사진을 함께 보냅니다.** LLM은 결함을 과하게 잡는 경향이 있어
(실측에서 88프레임 중 69장을 결함으로 봤습니다), 유형별 예시와 **정상 사진**을
같이 보여주면 판독이 안정됩니다.

> **[노후]로 바꾸면 자동으로 꺼집니다.** 노후관로는 두 모델이 학습한 영역이라
> 세 번째 의견이 필요 없고, 보이지 않는 채로 켜져 있어 모르는 사이에 외부 API를
> 부르는 일을 막기 위해서입니다.

## 성능 (검증 데이터셋 기준)

**두 모델의 학습 데이터를 모두 제외한 공통 검증셋**(`common_holdout`)에서
측정했습니다. 결함 12종 × 30장 = 360장이며, 학습에 쓴 사진과의 중복이
0장임을 파일 단위로 확인했습니다.

| 항목 | 결과 |
|---|---|
| **결함 유무 식별** (결함을 결함으로 잡는가) | **91%** / 88% |
| **결함명 식별** (두 AI 합집합) | **90%** |
| — 분류기 단독 | 41% |
| — 판독기 단독 | 62% |

앞의 두 값은 각각 분류기 · 판독기입니다.

**단독 성능이 낮은데 합집합이 90%인 것이 이 구조의 핵심입니다.** 두 모델이
동시에 맞히는 경우는 12%뿐이고, 나머지는 서로 다른 사진을 맞힙니다. 한쪽만
썼다면 62%에서 멈췄을 것을, 둘을 병렬로 놓아 90%까지 올렸습니다.

**역할이 다릅니다.**

| 구간 | 분류기 | 판독기 |
|---|---|---|
| 둘 다 학습한 8종 | 18% | **93%** |
| 판독기에 없는 4종 (BC·DF·DG·LD) | **86%** | 0% (클래스 없음) |

같은 결함을 두고 겨루면 판독기가 앞섭니다. 분류기의 값어치는 **판독기가
배우지 않은 종류를 메우는 것**과 **관 밖(자동차·지상) 오탐을 막는 것**입니다.

### 검증셋을 구성하는 결함 12종

| 코드 | 결함명 | 코드 | 결함명 |
|---|---|---|---|
| CC | 균열-원주 | JD | 이음부-단차 |
| CL | 균열-길이 | JF | 이음부-손상 |
| SD | 표면손상 | LP | 연결관-돌출 |
| BK | 파손 | DS | 토사퇴적 |
| BC | 좌굴 | DF | 변형 |
| LD | 라이닝 결함 | DG | 폐유부착 |

**제외한 유형** — 데이터가 부족한 희소 결함(CX 붕괴 · NS 역경사 · PB 막힘),
두 모델이 원본을 전량 학습에 써서 검증할 사진이 남지 않은 유형은 뺐습니다.

> **측정 조건** — 위 값은 잘라놓은 사진 판에서 나온 것입니다. 연속 실영상
> (카메라 이동 · 조명 변화 · 대부분이 평범한 구간)에서의 검증은 아직입니다.
> 또한 두 모델 모두 자기가 학습한 도메인에서 제 성능을 내므로,
> **실제 현장 성능은 위 숫자보다 낮게 보셔야 합니다.**

## 보안

**기본 구성은 외부와 통신하지 않습니다.** 두 모델 파일이 이 PC 안에서 직접
실행되며, 영상과 분석 결과가 외부로 나가지 않습니다.

단, **처음 설치할 때만** 인터넷이 필요합니다(파이썬 패키지 저장소 pypi.org 에서
내려받습니다). 설치가 끝난 뒤에는 인터넷을 끊어도 분석이 됩니다.

**LLM 판독만 예외입니다.** 이 기능을 켜면 해당 프레임 사진이 OpenAI·Google
서버로 전송됩니다. 그래서 다음과 같이 다뤘습니다.

| 방어 | 내용 |
|---|---|
| 기본 꺼짐 | 켜지 않으면 외부로 아무것도 나가지 않습니다 |
| 켜기 전 경고 | 설정 창에 주의 문구가 표시됩니다 |
| 자동 해제 | [노후]로 바꾸면 켜져 있어도 꺼집니다 |
| 키 미저장 | API 키를 디스크에 쓰지 않습니다 (창을 닫으면 사라집니다) |

**회사망·폐쇄망에서는 LLM 판독을 쓸 수 없습니다.** 이 경우에도 두 모델은
그대로 동작하므로 분석·보고서 출력에는 지장이 없습니다.

## 폴더 구성

```
실행하기.bat        ← 이것을 실행하세요
README.md           ← 이 문서
app/
  serve_demo.py     실행 진입점 (로컬 전용, 로그인 없음)
  setup_env.py      처음 실행 때 필요한 패키지를 자동 설치
  requirements.txt  필요한 파이썬 패키지 목록
  .venv/            자동 설치된 패키지 (처음 실행 때 생성)
  assets/
    best.pt         판독기 — YOLO11-L, 16종 탐지
    classifier.onnx 분류기 — EfficientNet-B0, 24종
    llm_examples/   LLM 판독에 같이 보내는 예시 사진 237장
  backend/          분석 파이프라인 (프레임 추출 · 추론 · OCR · 보고서)
  ui/               화면
```

압축을 풀면 **`실행하기.bat`과 `app` 폴더가 같은 위치에** 있어야 합니다.
