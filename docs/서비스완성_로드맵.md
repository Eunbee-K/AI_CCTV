## 2. Phase 1 — 실영상 베타테스트 (필수, 2~3주)

**왜 필요한가:**
- 현재 성능 수치는 **"잘라놓은 사진"** 기준 (정상:결함을 인위적으로 50:50으로 맞춤)
- 실제 연속 영상에서는 평범한 구간이 80%인데, 거기서 오탐이 많을 수 있음
- 카메라 이동, 조명변화 같은 실환경 요소를 처음으로 경험
- **이것 없으면 업체에 팔 수 없음** (신뢰도 차이 큼)

### 2.1 실행 방법

#### Step 1: 데이터 준비 (1주)

**필요한 것:**
- 실제 하수관로 CCTV 영상 **3~5개 파일** (각 5~10분)
- 기존 야장(조사표) 또는 전문가 검증

**어디서 구하는가:**
- 공단 내부 기존 프로젝트 영상
- 지자체/용역사에서 보유 중인 현장 영상
- 협력업체 CCTV 샘플

#### Step 2: 추론 실행 (1주)

```bash
# 앱 실행
python main.py  # 또는 serve_web_cpu.py

# 영상 선택 → 분석 → 결과 확인
```

**확인 사항:**
- 필터 정상/결함 판정 정확도
- YOLO 검출 위치(박스) 정확도
- OCR 거리·관경·관로번호 판독 오류 확인
- 엑셀 출력 형식 검증

#### Step 3: 검증 및 분석 (1주)

**필터 성능 평가:**
- 결함 놓침율 (recall) — 얼마나 빠뜨렸는가?
- 정상 오탐율 (FPR) — 정상을 결함으로 잘못 판정했는가?

**YOLO 성능 평가:**
- 박스 위치 정확도 — 결함 위치를 제대로 찾았는가?
- 클래스 정확도 — 균열을 균열로, 파손을 파손으로 맞췄는가?

**산출물:**
```
베타테스트_보고서.md
├─ 영상 메타정보 (이름, 길이, 촬영 환경)
├─ 필터 성능 지표
├─ YOLO 성능 지표
├─ 틀린 사례 분석 (각 케이스별 이미지 + 원인)
└─ 파인튜닝 계획
```

### 2.2 예상 결과

| 시나리오 | 다음 단계 |
|---|---|
| **성능 양호** (recall 90%↑, FPR <10%) | → Phase 2로 진행 |
| **성능 부족** (recall 70~90%) | → 데이터 추가 학습 또는 임계값 조정 |
| **큰 문제 발견** (recall <70%) | → 모델 재학습 필요 (2~3주 추가) |

## 3. Phase 2 — 파인튜닝 (필수, 1~2주)

### 3.1 미세 조정

**필터:**
- 임계값 최적화 (현재 0.9 → 재조정)
- 오탐이 많으면: 임계값 올리기 (recall 하락 감수)
- 놓침이 많으면: 임계값 내리기 (오탐 증가)

**YOLO:**
- Confidence 임계값 조정 (현재 0.10)
- 클래스별 가중치 재조정 (약한 클래스 강화)

### 3.2 추가 학습 (필요시)

**데이터가 부족하면:**
1. 베타테스트에서 틀린 케이스 **50~100개 추가 수집**
2. 라벨 정리
3. 필터/YOLO 재학습 (각 1~2일)

**지역/조건별 특화:**
- 신설 vs 노후 관로 분리 (재질 특성 차이)
- 지역별 조명/관경 특성 반영

### 3.3 검증

**재테스트:**
- 같은 베타 영상 5개로 재확인
- 성능 개선 여부 정량화

## 7. 주의사항

### ⚠️ 실수하기 쉬운 부분

1. **"잘라놓은 사진 성능"과 "실영상 성능"은 다르다**
   - 현재 수치는 참고만 할 것
   - 실영상이 진짜 성능

2. **베타 데이터가 학습 데이터와 중복되면 안 된다**
   - `used_files.csv`로 학습에 쓰인 파일 확인
   - 겹치는 것 제외하고 새 데이터만 테스트

3. **한두 개 영상으로는 부족하다**
   - 최소 3~5개 (서로 다른 환경, 현장)
   - 통계적 의미가 필요함

4. **성능이 안 좋아도 괜찮다**
   - 파인튜닝으로 개선 가능
   - 중요한 건 "왜 틀렸는가"를 파악하는 것

## 8. 성공 기준

**배포 승인:**
```
필터 recall ≥ 90% AND FPR ≤ 10% 그리고
YOLO 주요 클래스(CL, CC, BK, SD) detection ≥ 60%
```

**만족:**
```
필터 recall ≥ 85% 그리고
YOLO 주요 클래스(CL, CC, BK, SD) detection ≥ 50%
```

**개선 필요:**
```
위 기준 미만 → 추가 학습 또는 모델 수정
```
