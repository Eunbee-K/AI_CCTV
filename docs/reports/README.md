## 작성 규칙

- 파일명 `YYYY-MM-DD-<주제>.md`
- 구성: 요약 수치 → 요청 처리 → 확인 중 발견한 문제 → 검증 → 반영 → 남은 과제
- 항목은 **증상 / 원인 / 조치** 3단으로 쓴다
- 검증 수치는 실제로 돌린 결과만 적는다(추정치 금지)
- 잘못 짚었던 것도 적는다 — 테스트가 틀려 멀쩡한 기능을 실패로 판정한 경우 등
