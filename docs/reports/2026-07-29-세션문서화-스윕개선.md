이후 스윕이 **외장하드가 물려 있지 않아도** 돌아갈 수 있게 됐다 — 08-04 시스템 구조 보고서에서
설명한 "인터넷 없는 환경에서도 동작" 원칙과 짝을 이루는 변화다.

### 2.2 `run_sweep.py` — 재개 로직 신설

> 이 변경이 정확히 [`docs/reports/2026-08-04-학습자동화-시스템구조.md`](2026-08-04-학습자동화-시스템구조.md)에서
> "현재 구조"로 설명한 **3단계 재개**의 origin이다.

**이전(07-22 최초 버전)** — 학습이 끝나면 무조건 `last.pt`를 지우고, 성공하든 실패하든
`finally` 블록에서 임시 데이터셋을 항상 삭제했다. 중단되면 처음부터 다시 만들어야 했다.

**이후(이 커밋)** —

```python
# last.pt가 남아 있으면 이어서 학습
if last_pt.exists():
    model = YOLO(str(last_pt))
    train_metrics = model.train(resume=True)
else:
    model = YOLO(cfg["model"])
    train_metrics = model.train(data=str(data_yaml), ...)
```

- `last.pt`를 학습 완료 후에도 더 이상 지우지 않음
- 임시 데이터셋 삭제를 `finally`(항상)에서 **성공 시에만**으로 이동, 실패 시엔 보존
- 데이터셋이 이미 있으면(`data.yaml` 존재) 다시 만들지 않고 재사용

### 2.3 `mailer.py` — 가중치 자동 첨부

**이전** — 결과 요약표(CSV/xlsx)만 메일에 첨부됐다. 학습된 가중치를 보려면 워크스테이션에
직접 접속해야 했다.

**이후** — 새로 완료된 run의 `best.pt`를 자동으로 찾아 첨부한다.

```python
def find_best_weights(results_root, sweep_name, run_names, max_mb, log):
    """SMTP 첨부 용량 제한(보통 총 25MB) 대응으로, max_mb 넘으면 로그만 남기고 스킵"""
```

용량 제한(`mail_config.max_weight_attachment_mb`, 기본 20MB)에 걸리면 그 가중치만 빠지고
**요약표는 그대로 발송**된다 — 하나 때문에 전체가 막히지 않도록.
