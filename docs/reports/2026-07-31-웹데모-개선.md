## 1. 요청 처리

요청 중 절반가량은 표면 증상 아래에 다른 원인이 있었다. 아래는 실제로 무엇이 문제였는지 기준으로 정리한 것이다.

### Colab 연결 실패 — 원인 3개가 겹쳐 있었음

- **증상** — "연결됨"으로 표시되는데 추론이 되지 않고, 실패해도 아무 메시지가 없음
- **원인**
  1. `call_yolo_remote`가 에러 메시지를 만들어 놓고 `None`을 반환해 실패가 조용히 묻힘
  2. [연결] 버튼이 주소를 저장만 하고 서버 확인 없이 "연결됨" 표시
  3. `ngrok-skip-browser-warning` 헤더가 없어 JSON 대신 경고 HTML 수신
  4. `config.py`의 기본 주소가 **이미 죽은 터널**
- **조치** — 에러 반환 수정. [연결]이 `/predict` 존재 여부까지 실제로 확인하도록 변경하고, ngrok 에러코드를 원인별 한국어 안내로 변환

```
ERR_NGROK_3200 → "ngrok 터널이 없습니다. Colab에서 셀을 다시 실행해 새 주소를 받으세요."
ERR_NGROK_8012 → "ngrok은 살아있지만 Colab 안의 서버가 응답하지 않습니다."
/predict 404   → "서버는 응답하지만 /predict 엔드포인트가 없습니다."
```

### 영상 업로드 · 보고서 다운로드 — 경로 입력 방식 폐기

- **증상** — 영상은 서버 경로를 타이핑해야 했고, 보고서는 "저장 경로 입력" 방식
- **원인** — 웹에서 입력하는 경로는 **서버 PC를 가리킨다.** 접속한 사람 PC와 무관하므로 같은
  컴퓨터에서 열 때만 우연히 동작하고 있었다. 보고서는 서버에 파일이 생기고 사용자는 받지 못한다
- **조치** — 업로드는 **파일 선택 + 드래그앤드롭**(진행률 표시), 보고서는 **브라우저 다운로드**로 전환.
  업로드는 1MB 단위 스트리밍 저장, 파일명 정화(경로 조작 차단), 중복 이름 자동 회피.
  확장자 화이트리스트를 없애고 *실제로 열리는지*로 판단 — 현장 영상은 확장자가 제각각이다

```
보고서 파일명 자동 생성
CCTV조사표_가평군현리산유_1052.SD-A04-006_20260731.xlsx
        └ 현장명 ─┘ └─ 관로번호 ─┘ └ 날짜 ┘
```

### 결함 표기·열 구성 개편

- **변경** — 결함 코드에 한글명 병기 `BK(파손)`. 매뉴얼 25종 + 데이터셋 보조 6종, **총 31종** 매핑.
  관로번호는 영상당 1개 값이라 상단 입력칸으로 이동하고 표에서 열 제거. 오탐 열은 Del 키·행 삭제로 대체되어 삭제
- **주의** — 표시는 `BK(파손)`이지만 **편집할 때는 코드만** 나오게 했다. 표시 문구를 그대로 고치게
  두면 `BK(파손)` 전체가 결함 코드로 저장된다

### 반복 결함 그룹 펼치기 — 더블클릭이 안 먹던 문제

- **원인** — 토글 핸들러가 `refreshResults()`(서버 왕복)를 호출하고 있었다. 느릴 뿐 아니라
  요청이 실패하면 **토글이 조용히 먹통**이 된다
- **조치** — 마지막 데이터로 즉시 다시 그리도록 변경. **더블클릭 · Enter · ▶ 삼각형 클릭** 세 가지
  모두 동작하고, 접힘 상태가 삼각형으로 보인다

### 레이아웃 · 확대축소

- **비율** — 좌우 **1:1 기본** + 가운데 손잡이 드래그로 조절(브라우저에 저장, 더블클릭 시 복귀). 패널별 독립 스크롤
- **수정** — 세로가 짧다고 1단으로 접히던 문제(뷰포트 높이 조건 제거, 가로 820px 이하에서만 1단).
  축소가 `Math.max(1, …)`로 막혀 있어 25%까지 열었다
- **발견** — 신뢰도가 안 보이던 진짜 이유는 배율이 아니라 **라벨이 박스 바깥 위쪽에 붙어 있어서**였다.
  큰 박스일수록 화면 위 끝에 닿아 잘려나간다. 위에 공간이 없으면 박스 안쪽에 넣도록 수정

### 관로 구분 · 행 버튼 · 파비콘

- **신설 / 노후** 체크박스(배타 선택). 미선택 시 분석 실행 차단 — UI뿐 아니라 **서버에서도 검증**해
  API 직접 호출로 우회할 수 없게 했다
- **Del 키**로 선택 행 삭제. 입력칸에 커서가 있을 때는 글자만 지운다
- **행 추가/삭제 버튼**이 "안 먹던" 원인은 조용한 실패였다. 영상 미선택·행 미선택 시 아무 안내 없이 `return`만 하고 있었다
- `logo.ico`를 결과표·로그인 화면 **파비콘**으로 적용

## 2. 확인 중 발견해 함께 고친 결함

요청에 없었지만 그대로 두면 시연 중 문제가 될 것들. 검증 과정에서 드러났다.

### [치명] 영상 하나를 못 열면 앱 전체가 초기화되지 않음

`refreshQueue()`에서 `selectVideo()`가 예외를 던지면 `init()`이 통째로 중단된다.
결과표·업로드·Colab 패널까지 전부 죽는다. 삭제된 영상이나 지원 안 되는 코덱이면 바로 발생.
→ 로그만 남기고 나머지 초기화는 계속 진행하도록 수정.

### [데이터] 같은 시각에 행이 중복되면 편집·삭제가 어긋남

행은 `(영상, 시각)`으로 구분되는데 [+ 행 추가]가 같은 시각에 두 번째 행을 만들 수 있었다.
이후 편집·삭제가 엉뚱한 행에 걸린다. → 중복 추가 차단 + 사유 안내.

### 그 외

- **브라우저 캐시** — 서버는 새 파일을 주는데 화면이 그대로였다. 정적 파일에 `no-store` 헤더 추가.
  MJPEG 스트림을 막지 않도록 `BaseHTTPMiddleware` 대신 `StaticFiles`만 감쌌다
- **의존성 누락** — `itsdangerous`(서버 기동 실패), `python-multipart`(로그인 폼·업로드)가
  `requirements.txt`에 없었다
- **단독 행이 그룹 자식처럼 들여쓰기**되어 소속이 헷갈리던 문제
- **정적 파일 인증** — 로그인 없이 CSS를 요청하면 로그인 페이지가 반환된다(정상 동작).
  초기 점검 결과를 잘못 읽게 만든 원인이라 기록해 둔다

## 5. 남은 과제

"나중에 바꿀 것"으로 보류한 항목. 시연 범위가 사내를 넘어가기 전에 정리가 필요하다.

| 구분 | 항목 | 내용 |
|---|---|---|
| 보안 | 비밀번호가 평문이고 콘솔에 출력됨 | 서버 시작 시 `승인 계정: admin:admin1234`가 찍힌다. 코드에도 평문 비교. 외부 터널로 열기 전 해시(bcrypt) 전환 필요 |
| 동시성 | 사용자별 상태 격리 없음 | `state.py`가 싱글톤이라 두 사람이 동시 접속하면 분석 결과가 섞인다 |
| 기능 | 신설/노후가 보고서에 미반영 | 서버에 저장은 되지만 엑셀 출력에는 빠져 있다. 상단 공사명·관로번호 옆에 넣을지 결정 필요 |
| 설정 | 기본 Colab 주소가 죽은 터널 | `config.py`에 박혀 있어 앱을 새로 켤 때마다 그 주소가 다시 잡힌다. 다만 이제 [연결]이 확인하므로 조용히 실패하지는 않는다 |
| 배포 | 외부 접속 터널 · 구글 OAuth | 사무실 밖 시연에는 cloudflared 등이 필요하고, 계정 관리는 환경변수 방식이라 재시작해야 반영된다 |
