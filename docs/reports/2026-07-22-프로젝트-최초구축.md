### 2.1 앱 — `apps/AI_CCTV`

기존 tkinter 버전(`ver3.1_AI_CCTV_YOLO`)을 **pywebview 데스크톱 창 + HTML/JS 프론트엔드 +
FastAPI 백엔드** 구조로 이식한 것. 기존에 있던 GPT/Gemini 멀티모달 분석은 실제 파이프라인에서
쓰이지 않던 기능이라 이식 과정에서 뺐다.

**백엔드 (15개 모듈)**

| 파일 | 역할 |
|---|---|
| `main.py` | uvicorn을 백그라운드 스레드로 띄우고 pywebview 창을 연다 |
| `backend/server.py` | FastAPI 앱 구성 |
| `backend/analysis.py` | 분석 파이프라인 전체 조율 |
| `backend/ocr.py` | PaddleOCR로 구간 인식 · 메타데이터 추출 |
| `backend/frames.py` | 프레임 추출 |
| `backend/yolo_infer.py` / `yolo_remote.py` | YOLO 추론 (로컬 CPU / Colab 원격) |
| `backend/annotate.py` | 탐지 결과를 프레임에 그림 |
| `backend/rows.py` | 결과 그룹핑 (거리 중복 등) |
| `backend/excel_export.py` | 엑셀 보고서 출력 |
| `backend/state.py` | 앱 상태 (당시엔 메모리 전용) |
| `backend/ws_manager.py` | 실시간 진행상황 알림(WebSocket) |
| `backend/pywebview_api.py` | 네이티브 파일 대화상자 |
| `backend/routes/*` | analysis · config · export · results · videos 라우트 |

**프론트엔드 (`ui/`, 빌드 스텝 없는 vanilla JS ES 모듈)**

| 파일 | 역할 |
|---|---|
| `js/player.js` (322줄) | 영상 재생, 휠 확대/드래그 이동, bbox 오버레이 |
| `js/results-table.js` (434줄) | 결과표, 인라인 편집, 필터, 통계 |
| `js/filters.js` | 신뢰도·클래스 필터 |
| `js/app.js` | 전체 조율 |
| `js/ws.js` | 실시간 진행상황 수신 |
| `js/api.js` | 백엔드 API 클라이언트 |
| `css/styles.css` (448줄) | 전체 스타일 |

**당시 이미 갖추고 있던 기능**

- 영상 큐, 미리보기(재생/일시정지/탐색, 1~2.5배속) — avi/mkv 등 브라우저가 직접 재생 못 하는
  코덱도 OpenCV로 읽어 JPEG/MJPEG로 서빙
- 분석 실행: PaddleOCR로 조사 시작 구간 자동 인식 → 2초 간격 프레임 추출 → YOLO 탐지(로컬 또는
  Colab, 기본은 ngrok 고정 도메인) → 프레임 OCR로 거리·관경·현장명 보정 → 동일 거리 중복 시
  "확인필요" 표시
- 재생 중 실시간 bbox+결함명+신뢰도% 오버레이
- 결과표: 영상별 구분선, 거리 중복 그룹 접기/펼치기, 더블클릭 인라인 편집, 행 클릭/키보드
  ↑↓ 이동, 신뢰도·클래스 필터, "오탐" 체크
- 통계 탭: 영상별 × 결함 종류별 집계 (오탐 제외)
- 수동 행 추가/삭제, bbox가 그려진 프레임이 포함된 xlsx 보고서 출력

> **주목할 점** — 07-30·07-31 보고서에서 "고친" 기능 상당수(그룹 접기/펼치기, 인라인 편집,
> 신뢰도 필터, bbox 오버레이, 오탐 마킹)가 **이 최초 커밋에 이미 존재했다.** 이후 작업은
> 새 기능 추가보다 **웹 배포 환경에서 드러난 버그를 고치는 성격**이 컸다는 뜻이다
> (경로가 서버 PC를 가리키던 문제, 그룹 토글이 서버 왕복 때문에 먹통이던 문제 등).
