## 1. OCR 버그 — 최초 커밋(07-22)부터 있던 문제

### 한글 인식이 처음부터 안 되고 있었다

- **증상** — 현장명·조사시작 같은 한글 자막이 전부 빈 문자열로 나옴
- **원인** — 최초 커밋(2026-07-22, `b968155`)의 초기화 코드:
  ```python
  PaddleOCR(
      lang="korean",
      text_detection_model_name="PP-OCRv5_mobile_det",   # 속도 때문에 지정
      ...
  )
  ```
  **PaddleOCR 3.x는 `model_name`을 하나라도 지정하면 `lang="korean"`을 무시한다.**
  감지(det) 모델 속도를 올리려고 넣은 옵션이 인식(rec) 모델까지 기본값(비한글)으로
  끌고 가서, 한글이 조용히 실패하고 있었다. 에러가 나지 않아 알아채기 어려운 형태였다
- **조치** — 인식 모델을 명시
  ```python
  text_recognition_model_name="korean_PP-OCRv5_mobile_rec",
  ```

### 거리 판독 — 실측 37장 기준 35% → 94%

세 가지를 동시에 고쳤다.

| 문제 | 조치 |
|---|---|
| 화면 중앙의 **속도 표시**(`x.x m/min`)가 거리와 형식이 같아 혼동 | 파서에서 `m/min` 패턴을 먼저 제거 |
| 읽는 영역이 넓어(가로 45%) 속도 표시까지 걸림 | **30%로 좁힘** — 속도 표시 앞까지만 |
| 매치된 것 중 **마지막**(`[-1]`)을 사용 | 거리는 좌상단에 있으므로 **첫 번째**(`[0]`)로 변경 |

### 관경 — `Φ 200` 안정 추출

- 우상단 **재질 라인 영역**(가로 55~100%)을 읽는 대상에 추가
- 날짜(`2024-10-24`)·시간(`10:46:49`)을 **먼저 제거**하고 파싱 — 그 안의 숫자가 관경으로
  오인되던 문제
- 재질/관종(`PVC`·`흄관`·`오수` 등) **바로 앞의 3자리**를 우선 매칭하도록 우선순위 변경

## 2. 자막 오탐 필터 — 신규 (`overlay_filter.py`)

- **증상** — 화면에 박힌 자막(특히 우하단 위도/경도 숫자 블록)이 고대비 텍스처라
  **파손(BK)·균열 등으로 오탐**되고 있었다
- **조치** — OCR이 읽는 자막 위치와 동일한 6개 영역을 정규화 좌표로 정의하고,
  탐지 박스 면적의 **70% 이상**이 그 영역에 들어가면 결함에서 제외

```python
OVERLAY_TEXT_REGIONS = [
    (0.00, 0.00, 0.32, 0.24),   # 좌상단: 거리 / 관로ID
    (0.33, 0.00, 0.63, 0.12),   # 상단중앙: 이동속도
    (0.72, 0.00, 1.00, 0.16),   # 우상단: 날짜 / 시간
    (0.54, 0.09, 1.00, 0.22),   # 우중단: 관경 / 재질 / 관종
    (0.00, 0.80, 0.60, 1.00),   # 좌하단: 현장명
    (0.60, 0.68, 1.00, 1.00),   # 우하단: 맨홀깊이 / 위도 / 경도
]
```

임계값 0.70은 화면 대부분을 덮는 큰 탐지(관 전체)나 자막을 살짝 걸친 실제 결함은
유지되도록 잡은 값이다. `yolo_infer.py`·`yolo_remote.py` 양쪽(로컬·Colab 추론)에 적용.

## 3. 웹 데모 — 최초 구축

기존 `main.py`(pywebview exe)는 건드리지 않고, **브라우저로 접속하는 별도 진입점**을 새로 만들었다.

| 신규 파일 | 역할 |
|---|---|
| `serve_web.py` | 헤드리스 웹 진입점. `0.0.0.0` 바인딩, `AUTH_ENABLED=1` |
| `backend/auth.py` | 아이디/비번 로그인 게이트 (웹 배포에서만 활성화) |
| `ui/login.html` | 로그인 화면 |
| `apps/AI_CCTV/docs/WEB_DEMO.md` | 인수인계 문서 |

- 승인 계정은 환경변수 `AUTH_USERS`("아이디:비번,아이디2:비번2")로 관리, 기본값 `admin:admin1234`
- exe(pywebview)는 로컬 단일 사용자라 로그인 없이 그대로 동작 — 이 구분은 그대로 유지
- UI에 "추론 서버(Colab)" 연결 패널과 로그인 사용자 바/로그아웃 버튼 추가

> 커밋 메시지에 이미 명시돼 있던 한계 — **비밀번호 평문 비교(데모용)**, 구글 OAuth는 범위 밖.
> 두 항목 모두 이후 보고서(07-31, 08-03)의 "남은 과제"에도 반복해서 남아 있다.
