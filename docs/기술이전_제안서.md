# AI CCTV 하수관로 결함 탐지 시스템

## 1. 개요

완성된 **CCTV 하수관로 결함 탐지 AI 시스템** 서비스 실증 필요 과정

- **140,000장의 학습 데이터셋** (실제 현장 기반)
- **학습 완료된 모델 2개** (필터 EfficientNet-B0 + YOLO test3)
- **완전 자동화 파이프라인** (영상 분석 → 엑셀/PDF 보고서 자동 생성)
- **Windows 데스크톱 앱** (pywebview 기반, exe화 가능)

## 3. 남은 작업 (상생협력제 기술이전 후 진행)

### Phase 1: 실영상 베타테스트 (필수)

**왜 필요한가:**
- 현재 성능은 **"잘라놓은 사진"** 기준
- 실제 연속 영상(카메라 이동, 조명변화)에서 검증 필요
- 이것이 상용화 신뢰도를 결정함

**무엇을 할 것인가:**
1. 실제 하수관로 CCTV 영상 **3~5건** 수집
2. 필터 + YOLO 추론 실행
3. 야장(기존 조사표) 대조 검증
   - 필터: 결함 놓침률(recall), 정상 오탐률(FPR)
   - YOLO: 위치(박스) 정확도
4. 틀린 케이스 분석 → 미세 파인튜닝

**예상 소요 시간:** 2~3주  
**산출물:** 베타테스트 검증 보고서 + 파인튜닝된 모델

### Phase 2: 현장별 파인튜닝 (선택)

**대상:**
- 신설 vs 노후 관로 (재질별 특성 차이)
- 지역별 특화 (조명, 관경 분포)

**소요 시간:** 1~2주/지역  
**효과:** 각 지역별 정확도 +3~5%

### Phase 3: 기타 고도화 (선택)

| 항목 | 소요 시간 | 우선순위 |
|---|---|---|
| 세그멘테이션 연동 (test4_seg) | 1~2주 | 낮음 |
| 웹 사용자별 상태 격리 | 1주 | 낮음 |
| 모니터링 대시보드 | 2~3주 | 낮음 |

## 4. 기술 이전 구조 (K-eco 상생협력제)

### 4.1 처분 보상금 배분 (기술 판매 수익 기준)

예시: 기술이전가 **8,000만 원**

```
기술이전가: 8,000만 원
├─ 개인(개발자): 50% = 4,000만 원
├─ 공단(부): 10% = 800만 원
└─ 수탁기업(CCTV 업체): 40% = 3,200만 원
    (상용화 비용, 마케팅, 기술지원 등)
```

### 4.2 진행 절차

1. **사업계획서 제출** (공단 협력팀)
2. **기술개발심의위원회 심의** (월 1회)
3. **산업재산권 등록** (특허 출원/등록)
4. **기업과 수의계약** 체결
5. **처분 보상금** 지급 (판매 수익 발생 시)

## 5. 전달 범위

### 5.1 소스코드 & 문서
- `/apps/AI_CCTV/` — 데스크톱/웹 앱 전체
- `/backend/` — 추론, OCR, 엑셀 생성 로직
- `main.py`, `serve_web_cpu.py` — 실행 진입점
- 설치/실행/문제해결 가이드

### 5.2 학습된 모델
- `assets/classifier.onnx` — 필터 (EfficientNet-B0, 24클래스)
- `assets/best.pt` — YOLO (test3, 16종)
- `assets/filter.onnx` — 이진필터 (폴백)

### 5.3 학습 데이터 & 스크립트
- `AI_CCTV_DATASET/` — 140,000장 (이미지 + 라벨)
- `scripts/sweep/` — YOLO 자동화 학습 스크립트
- `scripts/classifier/` — 필터 학습 & 평가 스크립트
- `configs/sweeps/` — 학습 설정 (YAML)

### 5.4 실험 결과 & 보고서
- `docs/reports/` — 모델 선정 근거, 유출 분석, 성능 검증
- `docs/메타데이터(총괄).xlsx` — 31종 결함 코드 체계
- 학습 메타데이터 (`used_files.csv`, 검증 결과 등)
